# ebike-battery-frontend

Фронтенд заявочной системы по теме **«Оценка времени разряда аккумулятора электровелосипеда»**.
Курс «Разработка Интернет Приложений», ИУ5, 2026.

Разрабатывается с пятой лабораторной работы на стеке React + Redux + axios + React-Bootstrap.
Дизайн повторяет макет и стилистику бэкенд-приложения: палитра Bosch eBike, три экрана — лента режимов работы мотора, добавление, плитка.

Бэкенд: [ebike-battery-backend](../ebike-battery-backend).
