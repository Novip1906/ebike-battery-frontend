# ebike-battery-frontend

Фронтенд системы «Оценка времени разряда аккумулятора электровелосипеда»: велосипедист выбирает режим работы мотора Bosch eBike по расходу батареи (Вт·ч/км) и проценту поддержки. Курс «Разработка Интернет Приложений», ИУ5, 2026.

Стек: React 19, TypeScript, Vite, React-Bootstrap, React Router. Бэкенд: [ebike-battery-backend](https://github.com/Novip1906/ebike-battery-backend).

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на http://localhost:5173. В ЛР5 данные берутся только из mock-коллекции `src/modules/mock.ts`, веб-сервис, база данных и S3 не нужны.

## Меню

Нижняя панель из четырёх пунктов, текущий пункт выделен синим:

| Пункт | Адрес | Доступность |
|---|---|---|
| Лента | `/motor_modes/feed` | доступен |
| Добавление | `/motor_modes/draft` | недоступен до ЛР6 |
| Плитка | `/motor_modes` | доступен |
| Вход | `/riders/login` | недоступен до ЛР6 |

## Страница «Плитка режимов» — `/motor_modes`

- Слайдер «Расход батареи не более N Вт·ч/км» со шкалой от минимального до максимального расхода, по умолчанию стоит на максимуме.
- Кнопка «Найти» оставляет режимы с расходом не больше выбранного.
- Карточки в два столбца: фото, название, расход батареи, число лайков. Нажатие на карточку открывает режим в ленте.

## Страница «Лента» — `/motor_modes/feed/:motorModeId`

- Видео режима на весь экран, без `motorModeId` открывается первый режим.
- Название, краткое описание в две строки, кнопка «Ещё» раскрывает описание и запас хода на аккумуляторе 800 Вт·ч, «Скрыть» сворачивает.
- Поддержка мотора в процентах, расход батареи, число лайков.
- Кнопка «Следующий» открывает следующий режим, после последнего снова первый.

## Фото и видео по умолчанию

Если в режиме пустое `image_url` или `video_url`, подставляются `public/default_motor_modes.jpg` и `public/default_motor_modes.mp4`. В mock так сделано у режима Auto (нет фото и видео) и Cargo (нет видео).
