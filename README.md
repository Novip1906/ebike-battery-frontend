# ebike-battery-frontend

Фронтенд системы «Оценка времени разряда аккумулятора электровелосипеда»: велосипедист выбирает режим работы мотора Bosch eBike по расходу батареи (Вт·ч/км) и проценту поддержки, ставит лайки и добавляет свои режимы. Курс «Разработка Интернет Приложений», ИУ5, 2026.

Стек: React 19, TypeScript, Vite, React-Bootstrap, React Router, Redux Toolkit, axios. Бэкенд: [ebike-battery-backend](https://github.com/Novip1906/ebike-battery-backend), ветка `motor_modes_jwt`.

## Лабораторная работа 7

Демоверсия открывает плитку режимов и ленту с фотографиями и видео из комплекта приложения. На телефоне откройте её в Chrome и выберите «Установить приложение» или «Добавить на главный экран». В Safari эта команда находится в меню «Поделиться». После первой полной загрузки PWA открывается без интернета. Фильтр расхода сохраняется при переходе к режиму и обратно. [Открыть демоверсию на GitHub Pages](https://novip1906.github.io/ebike-battery-frontend/)

Для демонстрации входа, своих режимов и добавления используется локальный веб-сервис. Ноутбук и телефон должны находиться в одной сети Wi-Fi.

```bash
npm ci
npm run cert:lan
npm run lan
```

Для выпуска сертификата нужен OpenSSL. Если у ноутбука несколько сетевых интерфейсов, передайте адрес Wi-Fi явно, например `npm run cert:lan -- 192.168.1.10`. Команда печатает ссылку с этим IP и портом 4173. При смене IP повторите выпуск сертификата и перезапустите фронтенд.

Перед первым открытием ссылки передайте на телефон публичный сертификат `.certs/ebike-ca.cer` и сверьте отпечаток SHA-256 с выводом команды. На Android в настройках безопасности выберите установку сертификата центра сертификации. На iPhone установите полученный профиль и включите доверие в «Настройки → Основные → Об этом устройстве → Доверие сертификатам». Закрытые ключи хранятся в `.certs/` на ноутбуке. Запустите Go API на порту 8080 и хранилища из Docker Compose по инструкции репозитория бэкенда. Браузер телефона обращается к `https://<IP ноутбука>:4173` за страницами, API и медиа. При недоступном API LAN-версия показывает ошибку загрузки. [Запуск бэкенда](https://github.com/Novip1906/ebike-battery-backend/tree/motor_modes_jwt#запуск)

Сборка для Pages создаётся командой `npm run build:pages` в `dist-pages/`. Исходники хранятся в `motor_modes_pwa`. При push GitHub Actions собирает приложение и записывает содержимое `dist-pages/` в ветку `gh-pages`. В Settings → Pages выбран источник Deploy from a branch, ветка `gh-pages`, папка `/(root)`. Для ручной сборки и публикации из ветки исходников выполните `npm run deploy`. Для локального просмотра сборки выполните `npm run preview -- --mode pages --port 4174` и откройте `http://localhost:4174/ebike-battery-frontend/`. Статические ссылки вида `#/motor_modes/feed/1` открывают выбранный режим напрямую. [Задание ЛР7](https://github.com/iu5git/Web#лабораторная-7) · [Методические указания](https://github.com/iu5git/Web/blob/main/tutorials/pwa/PWA.md)

## Запуск на ноутбуке

```bash
npm ci
npm run dev
```

Приложение открывается на http://localhost:4173. Предпросмотр сборки (`npm run build`, затем `npm run preview`) использует тот же порт. Если порт занят, Vite сообщает об этом при запуске. Веб-сервис должен работать на http://localhost:8080, MinIO на http://localhost:9000 (запуск описан в README бэкенда). Без веб-сервиса гость видит плитку и ленту из mock-коллекции `src/modules/mock.ts`.

## Прокси

CORS решён проксированием в `vite.config.ts`, браузер обращается только к адресу фронтенда:

| Маршрут фронтенда | Куда уходит запрос |
|---|---|
| `/api/...` | веб-сервис `http://localhost:8080/api/...` |
| `/minio/...` | MinIO `http://localhost:9000/...` |

Адреса фото и видео из ответов веб-сервиса (`http://localhost:9000/ebike-motor-media/eco_mode.jpg`) переписываются в `/minio/ebike-motor-media/eco_mode.jpg`.

## Кодогенерация

Клиент веб-сервиса `src/api/Api.ts` генерируется из swagger бэкенда утилитой `swagger-typescript-api` (axios):

```bash
npm run generate-api
```

Скрипт `scripts/generate-api.mjs` берёт спецификацию с http://localhost:8080/swagger/doc.json. Экземпляр клиента `api` в `src/api/index.ts` добавляет заголовок `Authorization: Bearer <JWT>` после входа.

## Состояние Redux

| Срез | Что хранит | Thunk |
|---|---|---|
| `rider` | логин велосипедиста, `isAuthenticated`, ожидание входа или выхода (`authPending`) | вход и выход через axios без thunk |
| `motorModes` | фильтр `maxConsumptionWhPerKm`, карточки плитки, границы расхода | `getMotorModesList`, `deleteMotorMode` |
| `motorModeFeed` | текущий режим ленты | `getMotorModeFeed`, `likeMotorMode` |
| `motorModeDraft` | черновик режима велосипедиста | `getMotorModeDraft`, `createMotorModeDraft`, `publishMotorModeDraft`, `deleteMotorModeDraft` |

Пока выполняется запрос, поверх страницы показывается анимация загрузки, кнопки заблокированы. JWT после входа лежит в `localStorage` под ключом `rider_access_token`. После обновления страницы по F5 Redux возвращается в состояние гостя, а при выходе фильтр плитки сбрасывается.

## Меню

Нижняя панель из четырёх пунктов, текущий пункт выделен синим:

| Пункт | Адрес | Гость | Велосипедист |
|---|---|---|---|
| Лента | `/motor_modes/feed` | доступен | доступен |
| Добавление | `/motor_modes/draft` | недоступен | доступен |
| Плитка | `/motor_modes` | доступен | доступен |
| Вход / Выход | `/riders/login` | «Вход» открывает страницу входа | «Выход» завершает сессию |

## Страница «Плитка режимов» — `/motor_modes`

- Слайдер «Расход батареи не более N Вт·ч/км» со шкалой от минимального до максимального расхода. Значение хранится в Redux и сохраняется при переходе между страницами.
- Кнопка «Найти» запрашивает у веб-сервиса режимы с расходом не больше выбранного (`GET /api/motor_modes?max_consumption_wh_per_km=N`).
- На телефоне плитка показывает два столбца, с 640 пикселей три, с 1024 пикселей четыре. В карточке видны фото, название, расход батареи и число лайков. Нажатие открывает режим в ленте.
- У своих режимов велосипедиста (`created_by_current_rider = 1`) есть кнопка «Удалить».

## Страница «Лента» — `/motor_modes/feed/:motorModeId`

- На телефоне видео занимает фон ленты, на широком экране располагается рядом с параметрами. Без `motorModeId` открывается первый режим.
- Кнопка возле названия приостанавливает и возобновляет воспроизведение. При включённом в системе сокращении движения видео ждёт нажатия.
- Название, краткое описание в две строки, кнопка «Ещё» раскрывает описание и запас хода на аккумуляторе 800 Вт·ч, «Скрыть» сворачивает.
- Поддержка мотора в процентах, расход батареи, число лайков. Велосипедист нажатием на сердце ставит или снимает лайк.
- Кнопка «Следующий» открывает следующий режим, после последнего снова первый.

## Страница «Добавление» — `/motor_modes/draft`

- Без черновика: поля «Фото режима», «Видео режима» (предпросмотр выбранных файлов), «Название режима» и кнопка «Далее» создают черновик с загрузкой файлов в MinIO.
- С черновиком: фото и видео из MinIO, поля «Название режима», «Краткое описание», «Поддержка мотора, %», «Расход батареи, Вт·ч/км», кнопки «Опубликовать» и «Удалить черновик». После публикации открывается режим в ленте.

## Страница «Вход» — `/riders/login`

Велосипедист вводит логин и пароль и нажимает «Войти». Для проверки входа используйте `ivan_rider` / `velo2026`.

## Фото и видео по умолчанию

Если в режиме пустое `image_url` или `video_url`, подставляются `public/default_motor_modes.jpg` и `public/default_motor_modes.mp4`.
